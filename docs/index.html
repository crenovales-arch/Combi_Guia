Problemáticas Detectadas

El proyecto busca resolver los problemas de comunicación visual presentes en las rutas de combi que conectan Naucalpan con la Ciudad de México, donde la información no está disponible para los nuevos usuarios.

Objetivo del Proyecto

El objetivo general es diseñar un sistema de señalética claro y funcional para orientar mejor a los usuarios. El caso de estudio se centrará en rutas de transporte ubicadas en Naucalpan de Juárez, Estado de México.

Sistema de Mapas

Se propone la creación de un sistema de mapas digitales y físicos que muestren claramente las rutas, paraderos y conexiones. Esto incluirá la generación de datos abiertos para facilitar la planeación urbana y el análisis de movilidad.
