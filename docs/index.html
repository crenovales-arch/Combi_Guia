MAPA DE RUTAS

Sistema de rutas Naucalpan - CDMX

La movilidad entre el Estado de México y la capital del país padece de un silencio visual. Este proyecto de investigación y diseño interviene las rutas concesionadas de Naucalpan para proponer un sistema de señalética que facilite la orientación del usuario.

Problemáticas Detectadas

El proyecto busca resolver los problemas de comunicación visual presentes en las rutas de combi que conectan Naucalpan con la Ciudad de México, donde la información suele ser limitada, dispersa o difícil de interpretar para quienes utilizan este sistema de transporte por primera vez.

Objetivo del Proyecto

El objetivo general del proyecto es diseñar un sistema de señalética claro, funcional y fácil de comprender que contribuya a mejorar la orientación de los usuarios dentro de las rutas de transporte colectivo.

Sistema de Mapas

Se desarrolló un sistema de mapas digitales y físicos que permite visualizar de manera clara y accesible las rutas de transporte, los principales paraderos y las conexiones existentes entre distintos puntos de la red.
